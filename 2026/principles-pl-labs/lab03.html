Solving numerical constraints


type Type =
  // Two primitive types
  | Number
  | String

  // Function from t1 to t2
  | Function of Type * Type

  // Tuple with t1 and t2
  | Tuple of Type * Type

  // Later additions
  | TypeVariable of string

  // Record type
  | Record of Map<string, Type>

Recursive data type!

  • int (primitive)
  • string (primitive)
  • int -> int
  • int * string
  • 'a (type variable)
  • anonymous records
